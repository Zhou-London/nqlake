# NQ Lake 0.3.0

The console's UI moves from shadcn/ui and Radix UI to HeroUI. The API and the
backend are unchanged; every console page and interactive component is
touched.

## Console

- `@heroui/react` and `@heroui/styles` replace `shadcn`, `radix-ui`,
  `class-variance-authority`, `next-themes`, and `tw-animate-css`.
  `next-themes` had never been wired into the app, so this drops an unused
  dependency along with the ones the migration retires. `components.json`,
  the shadcn config file, is gone.
- Every native `<select>` is now a `SelectField` (or `FormSelect` for
  react-hook-form-backed fields): the table filter and sort controls on the
  data catalog, the row limits on the SQL workspace and a table's data
  preview, and the column type pickers when creating a table or adding a
  column. Each opens as a proper listbox popover instead of the browser's
  native dropdown.
- Checkboxes bound to a form field (the required-column flag when creating
  a table, and the create-if-not-exist and overwrite confirmations in
  Parquet import) move to a `FormCheckbox` that binds directly to a
  react-hook-form field. The lossy-repair confirmation, which isn't part of
  a form, uses the plain `Checkbox`.
- Dialogs, tabs, and buttons keep the same behavior but sit on HeroUI's
  `Modal`, `Tabs`, and `Button` underneath. The close button in every dialog
  and the active-tab indicator on every tab bar now come from HeroUI's own
  styling instead of a hand-rolled one.
- The color tokens behind `panel`, `eyebrow`, and the other shared classes
  in `globals.css` are renamed and re-tuned: backgrounds separate into
  `surface`, `surface-secondary`, and `surface-tertiary`, and status colors
  route through HeroUI's `accent`, `default`, `success`, and `warning`
  tokens instead of ad hoc Tailwind shades.
- The page heading on Overview, the data catalog, the SQL workspace,
  Parquet import, and Services now carries a one-line description; it used
  to be left blank.
- Overview gained a fourth stat tile, **Healthy services**, showing the
  count of services currently passing their health check.
- The mobile navigation menu (below the `lg` breakpoint) is now a dialog
  instead of a slide-out panel with a tap-to-dismiss backdrop, and offers a
  **User guide** shortcut of its own.
- The workspace search dialog (Cmd/Ctrl+K) placeholder reads "Search
  workspace…" instead of "Search tables…", since it also matches pages.
- The services indicator in the header reads "Systems operational" instead
  of "All systems operational", and the footer tagline that used to follow
  "Apache Iceberg / DuckDB" is gone.

## Upgrading a checkout

1. Run `npm install` in `console/` to pick up the dependency change; the
   lockfile is part of this release.
2. No `.env` or Makefile changes are needed.

## Known limits

Unchanged from 0.2.0: no authentication, catalog-wide refreshes scale with
table count, row previews of large tables take over a second, SQL workspace
history and **Stop waiting** don't reach the server, column types are a
fixed list outside Parquet upload, `/docs` is outside the proxy, a running
console must be stopped to pick up new code, and the console is light theme
only.
