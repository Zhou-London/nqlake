# NQ Lake 0.4.0

The console is rebuilt on [NQUI](https://github.com/Zhou-London/nqui), the
`@nowquant/nqui` component kit, and on nothing else. HeroUI, sonner,
react-hook-form, zod, geist, clsx, and tailwind-merge are gone, and so is
every hand-written UI component under `components/ui/` and `shared.tsx`.
The API and the backend are unchanged.

## Console

- `@nowquant/nqui` 0.4.1 is the only UI dependency; `@nowquant/nqui/sql`
  pulls in CodeMirror 6 for the SQL editor. `globals.css` is two lines:
  Tailwind and the NQUI theme. There is no custom CSS, no `cn`, and no
  wrapper component; pages compose NQUI directly.
- The frame is `AppShell` with a `Sidebar`, a transparent `Navbar` holding
  the `SidebarTrigger`, breadcrumbs, the workspace search button, a
  service-health `StatusDot`, and a light/dark toggle (`useTheme`). Below
  768 px the sidebar is NQUI's drawer.
- Workspace search (Cmd/Ctrl+K) is a `CommandPalette` with a Tables section
  and a Pages section; the user guide is a `Modal` of `CardRow`s.
- Every table list is a `DataGrid`. The catalog's search box, namespace
  filter, sort, and pager are the grid's own toolbar, column filter, column
  sorting, and pagination; **Browse tables** on a namespace card sets the
  grid's namespace filter. Query results and row previews use the same grid
  with a CSV export in its toolbar.
- Forms are NQUI `Form` with native validation (`isRequired`, `validate`)
  on `TextField`, `TextArea`, `Select`, and `Checkbox`; errors render in the
  field's own error slot. Server errors show as an `Alert` in the dialog.
  Buttons that cannot proceed say why through `disabledReason`.
- The SQL workspace uses `SqlEditor` (CodeMirror, `lake.<ns>.<table>`
  completion from the loaded catalog, Cmd/Ctrl+Enter) and a `SchemaTree`
  of namespaces, tables, and typed columns; clicking a table inserts its
  query. History is a `Table` whose rows load the query on click.
- Parquet import uses `FileUpload` for the drop zone and file list, a
  `Table` for the inspected columns, and an `Alert` per type repair. The
  three-step progress indicator is removed: NQUI has no stepper.
- Overview and table stats are `KpiCard`s; namespace cards use `Stat`;
  table properties render in `JsonViewer`; the Manage tab is a `CardStack`
  of `CardRow`s; empty and error pages are `EmptyState`.
- Toasts come from NQUI's `toast`, mounted by `NquiProvider`, which also
  routes every `href` through the Next.js router.

## Upgrading a checkout

1. Run `npm install` in `console/`; the lockfile is part of this release.
2. No `.env` or Makefile changes are needed.

## Known limits

Unchanged from 0.3.0 except that the console now follows the OS color
scheme and offers a toggle. The stored scheme is applied after hydration,
so a dark-mode reload paints light for one frame.
